# Manual walkthroughs

Criteria marked *(Verify: manual)* are checked by following a written walkthrough (NFR-12.6). Write
one file per milestone, `M<n>-<name>.md`, when the milestone's features exist, and record each run.

## Template

```markdown
# M<n> walkthrough

Build: <commit>, <32-bit / 64-bit>, Windows <version>, <screen scale>

| Criterion | Steps | Expected | Result |
|---|---|---|---|
| UI-04.2 | 1. … 2. … | … | Passed / Failed: <what happened> |
```

Mark each result in the spec tracker as well.
