About this tracker
Source
The spec files in docs/specs of the repository.
Status
Each acceptance criterion is Not started, Passed or Failed. Everyone who can open this page sees changes live; people with Contributor access or higher can change them. The page records who set a status and when.
Feature status
Passed when all its criteria passed, Failed when any failed, In progress when some passed, otherwise Not started.
Milestone
Done when all its Must criteria passed. Failing when a Must criterion failed.
Priority
Must is needed for its milestone. Should can slip one milestone. Could is nice to have.
Check
unit, integration, contract (recorded responses or a mock server), parity (compared with the old app), security, CI, or manual (a written walkthrough).
Left out
Withdrawn features and criteria. The hook plugin spec (HOOK, milestone M7) is a placeholder with no criteria yet.
